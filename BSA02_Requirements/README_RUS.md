# BSA02 — Требования

## Описание проекта

Проект посвящён работе с требованиями к ПО: их видами и уровнями, моделями as is / to be, контекстной диаграммой и проверкой потоков данных. Работа велась на кейсах «Запись на стрижку» и «Доставка заказов».

## Что было сделано

- `ex00_bbs_asis.xlsx`
  Таблица ролей и их действий в текущем состоянии (as is) по задаче «Запись на стрижку» — 19 строк с указанием проблем, возникающих у каждой роли.

- `ex00_del_asis.xlsx`
  Таблица ролей и действий as is по задаче «Доставка заказов» — 20 строк с проблемами.

- `ex01_del.jpg`
  Контекстная диаграмма системы доставки: стейкхолдеры, их действия и потоки данных, которыми они обмениваются с системой (7 внешних сущностей).

- `ex02_bbs_tobe.xlsx`
  Доработанная таблица из ex00 по задаче «Запись на стрижку»: для каждой проблемы указано состояние to be и решение — 19 строк.

- `ex02_del_tobe.xlsx`
  Доработанная таблица as is / to be по задаче «Доставка заказов» — 20 строк с решениями проблем.

- `ex03_bbs_streams.xlsx`
  Проверка входных/выходных потоков данных по задаче «Запись на стрижку» относительно контекстной диаграммы — 14 потоков, отмечены расхождения.

- `ex03_del_streams.xlsx`
  Проверка потоков данных по задаче «Доставка заказов» — 16 потоков.

- `ex04_bbs_glossary.xlsx`
  Глоссарий проекта «Запись на стрижку», пополненный на 20 терминов (55 всего), и обновлённый каталог стейкхолдеров (8 позиций, включая одного нового).

- `ex04_del_glossary.xlsx`
  Глоссарий проекта «Доставка заказов», пополненный на 24 термина (59 всего), и обновлённый каталог стейкхолдеров (9 позиций, включая одного нового).

## Итоги

Проект дал практические навыки анализа требований: описание текущего состояния процессов (as is), проектирование целевого состояния с системой (to be), построение контекстной диаграммы и проверку согласованности потоков данных с ней. Эти артефакты формируют основу для последующего формулирования бизнес- и функциональных требований к системе.
